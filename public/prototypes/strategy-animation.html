Where you already use Strategy

      
    
        
  • Python sorted(items, key=...) and max(..., key=...): the key function is the strategy.
    • 
        
  • Scala list.sorted(using ordering) and Java Comparator: the ordering is the strategy.
    • 
        
  • Machine learning: swapping optimisers (SGD, Adam) into the same training loop in PyTorch.
    • 
        
  • Spark: a custom Partitioner decides how records are spread, without changing the job.
    • 
        
  • Cloud SDKs: configurable retry modes (e.g. boto3's standard and adaptive) are interchangeable retry strategies.
    • 
        
  • Payment gateways, shipping calculators, tax rules and route planners that pick a rule per order, country or user.
